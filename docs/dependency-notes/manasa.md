# Dependency note — Manasa (MAN-09)

Compression crates needed for `MAN-06` (BZ2 NCD), `MAN-07` (LZMA NCD), and
`MAN-08` (ZLIB NCD). Per the PRD's dependency rule, I don't edit
`Cargo.toml` myself — this note is the handoff for Simha Teja to review and
add via `DEP-02`. Once added, I validate under `DEP-03`.

## Candidates

| Algorithm | Crate | Backing library | System dependency |
| --- | --- | --- | --- |
| BZ2 NCD | `bzip2` | libbz2 (C, via `bzip2-sys`) | Yes, unless built with a vendored/static feature |
| LZMA NCD | `xz2` | liblzma (C, via `xz2-sys` / `lzma-sys`) | Yes, unless built with a vendored/static feature |
| ZLIB NCD | `flate2` | `miniz_oxide` (pure Rust, default backend) | **No** — no system dependency by default |

Recommended feature flags:

- `bzip2 = { version = "0.4", features = ["static"] }` — bundles/vendors
  libbz2 at build time instead of requiring it preinstalled on every dev
  machine and CI runner. Avoids "works on my machine" build failures.
- `xz2 = { version = "0.1", features = ["static"] }` — same reasoning,
  vendors liblzma instead of requiring a system install.
- `flate2 = "1"` — default features are sufficient (`miniz_oxide` backend);
  no vendoring needed since there's no system dependency to begin with.

## Settings that must match the Python source exactly

- **BZ2 NCD**: source uses `codecs.encode(data, 'bz2_codec')`, Python's
  default `bz2` compression level (9, the stdlib default). Rust side should
  use `bzip2::Compression::best()` (or explicit level 9) to match, not the
  crate's own default if it differs.
- **LZMA NCD**: source uses `lzma.compress(data)`, which defaults to
  `FORMAT_XZ` (the XZ container format, not raw LZMA1/LZMA2). `xz2`'s
  `write::XzEncoder` also produces XZ-format output by default — same
  underlying `liblzma` library as Python uses, so this is the
  **lowest-risk** pairing of the three: both sides call the literal same C
  library, not two independent reimplementations.
- **ZLIB NCD**: source uses `codecs.encode(data, 'zlib_codec')`, which
  produces RFC 1950 zlib-wrapped output (2-byte header + deflate payload +
  4-byte Adler-32 trailer) at zlib's default compression level (6).
  `flate2::write::ZlibEncoder` (not `DeflateEncoder`, which omits the
  header/trailer) produces the same RFC 1950 framing — use
  `Compression::default()` (level 6) to match.

## Fixed expected-output risk (per algorithm, from the behavior cards)

- **BZ2 NCD**: only 2 frozen fixture values exist
  (`docs/behavior-cards/manasa/bz2-ncd.md`). Even with the same underlying
  approach, exact byte-length parity with Python's `bz2_codec` isn't
  guaranteed — document any deviation in `DECISIONS.md` rather than chasing
  byte-perfect parity, per the team's already-agreed fallback.
- **LZMA NCD**: **zero** frozen fixture values exist in `tests/original/`
  (confirmed by grep — the only reference to `lzma` in the frozen suite is
  a commented-out exclusion line). Worked examples in
  `docs/behavior-cards/manasa/lzma-ncd.md` were generated by running the
  real, unmodified `textdistance.lzma_ncd` locally, not pulled from a
  frozen fixture — lower-confidence ground truth than every other card.
  This is the highest-risk of the three algorithms to validate.
- **ZLIB NCD**: no dedicated fixed-value test file either, but it **is**
  covered by `tests/original/test_compression/test_common.py`'s shared
  property tests (symmetry, monotonicity, normalization) — a lighter gap
  than LZMA's.
